# Scoring matrix template

Read this when a comparison needs weighted scoring, or the user asks for a scored table. A qualitative comparison does not need it.

1. **Gates first.** One row per option, PASS / FAIL / UNKNOWN per gate. A FAIL removes the option; an UNKNOWN keeps it as conditional.
2. **Criteria and weights.** List each criterion with its weight (weights sum to 100%) and a one-line anchor for each score, for example Ops effort: 1 = full-time owner, 3 = a few hours a week, 5 = near zero.
3. **Scores.** 1–5 per criterion, each with a short evidence note and its source or date.

| Option | Gates | Criterion A (w%) | Criterion B (w%) | Criterion C (w%) | Weighted score | Evidence confidence |
| --- | --- | --- | --- | --- | --- | --- |

4. **Compute the total with a tool** and check that the weights sum to 100%. Do not score missing evidence as zero; show a range or mark the option conditional.
5. **Sensitivity.** Shift weight between the two most contested criteria, re-rank, and report whether the order changes. If two options are within about 0.3, call it a near tie.
6. **What would change the result:** the one fact or test that could reverse the ranking.
